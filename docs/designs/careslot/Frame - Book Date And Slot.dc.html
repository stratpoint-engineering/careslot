DES-006 · Book Date And Slot

Epic E003 · serves US-003, FR-BOOK-002, FR-BOOK-003, AC-007, AC-008, AC-012

  • Changing the date reloads the free times (htmx). The date picker allows today up to 30 days ahead only (AC-007).
  • Only free times that haven’t started are shown; a time starting in a few minutes is still offered (AC-008).
  • Each time is a Button; tapping it goes to step 3.
  • Breakpoints: one layout serves all widths: one card, max 420 px, centred; below 452 px it fills the width with 16 px margins (phones first).
  • Session timeout: after 30 minutes without activity the next click opens Sign in with the idle message (DES-002).
  • Names, dates and clinics in this frame are sample content.
